9. Upload source code to GitHub
1) installing git:  https://git-scm.com/install/windows
2) creating ssh keygen:  terminal) ssh-keygen  ->  enter  ->  cat ~/.ssh/id_ed25519.pub  ->  copy
3) enrolling ssh key to GitHub:  GitHub  ->  Settings  ->  SSH and GPG keys  ->  New SSH key  ->  paste & Add SSH key
4) uploading code to GitHub:  New Repository  ->  Example_AI_Tutor  ->  Create Repository  ->  terminal) move to the code directory  ->  rm -rf .git  ->  git init  ->  git add .  ->  git add -f charts data imgs  ->  git status  ->  git config --local user.name "my_name" // user.email "my_email"  ->  git commit -m "first commit"  ->  git remote add origin https://github.com/Pedro-tteokbokki/example_codes.git  ->  git push -u origin main  ->  refresh GitHub
